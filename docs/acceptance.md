Release verification update: the automated Android framework run initially reported a successful job despite instrumented failures because a shell pipeline masked the test exit code. The workflow now enables `pipefail` and retains logcat diagnostics. Its Android 16 receipt-recovery and normal-role tests passed, but the origin-bound OTP receipt assertion failed; Android 17 instrumentation crashed before its first assertion. These automated gates are **FAIL**, pending correction and a new run. They do not replace the earlier manually observed Android 16 SMS result above.

The 0.1.1 Firebase sign-in flow failed on a physical installer: its encrypted-preference context wrapper was cast to `Application` by the SDK. The correction uses the real application context and intercepts Firebase preferences in the application class. An Android 16 instrumented regression now initializes the real Firebase Auth SDK and verifies encrypted preference persistence. Physical Google sign-in remains **NOT TESTED** until the corrected release is installed and observed.

Update rows only after the corresponding assertion or observed result. Do not broaden a unit result to untested physical behavior.

Initial experimental APK 0.1.0 was withdrawn after emulator testing revealed that a legacy default-SMS lookup disagreed with the granted Android role. Version 0.1.1 uses RoleManager and passed replay of retained encrypted receipts. Physical release gates remain open.

The signed 0.1.1 APK installed through adb without permission overrides, became the Android 16 SMS-role holder through system consent, received a fourth synthetic SMS offline, persisted it, and posted an OTP notification. Release clipboard verification was interrupted by repeated emulator System UI ANRs; debug clipboard verification passed earlier. These emulator results do not establish carrier or OEM reliability.

Current framework evidence: the corrected CI run passed encrypted-journal recovery across a process restart, interrupted AtomicFile replacement, upload revision acknowledgement, synthetic MMS codec, Firebase Auth initialization with encrypted preferences, and normal system SMS-role selection on both API 36 and API 37. Its origin-bound OTP receipt assertion still failed. The radio fixture is being corrected and diagnostic artifacts enabled before another run; immediate Android 17 OTP receipt/copy is not yet a passing gate.
